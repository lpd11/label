ใส่รหัสผ่าน

ใส่ครั้งเดียว เครื่องนี้จะจำไว้ รายชื่อลูกค้าจะตรงกันทุกเครื่อง

ตั้งค่า Google Sheet ครั้งแรก / เปลี่ยนรหัสผ่าน (ทำที่คอม)
  1. พิมพ์รหัสผ่านที่ต้องการในช่องด้านบน (อย่างน้อย 6 ตัว) แล้วกด
  2. เปิด Google Sheet "ฐานข้อมูลผู้รับพัสดุ" ไปที่ Extensions > Apps Script
  3. ลบโค้ดเดิมทั้งหมด วางโค้ดที่คัดลอกมา กด Save
  4. กด Deploy > Manage deployments กดรูปดินสอ ตรง Version เลือก New version แล้วกด Deploy
  5. กลับมากด เข้าใช้งาน

โค้ดเก็บรหัสผ่านเป็นค่าแฮช ไม่ใช่ตัวรหัสจริง ถ้าลืมรหัสก็ตั้งใหม่ด้วยขั้นตอนนี้ได้ (เครื่องอื่นต้องใส่รหัสใหม่)
