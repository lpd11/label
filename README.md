# พิมพ์ใบปะหน้าพัสดุ

เว็บพิมพ์ใบปะหน้าพัสดุ ใช้กันในบ้าน 2 คน รายชื่อลูกค้าซิงค์ผ่าน Google Sheets

- เว็บ: https://lpd11.github.io/label/
- ไฟล์เดียว: `index.html` (push ขึ้น `main` = deploy ผ่าน GitHub Pages)
- ข้อมูล: Google Sheet "ฐานข้อมูลผู้รับพัสดุ (Shipping Recipients)" แท็บ `Recipients`

## v1.0 — 15 ต.ค. 2569

### ใช้งาน
- **ครึ่ง A4** (ค่าเริ่มต้น): พิมพ์บน A4 แนวตั้ง แผ่นละ 2 ใบ (ใบละ 210 × 148 มม.) มีเส้นประกลางแผ่นไว้ตัด
- **A4 เต็ม**: A4 แนวนอน แผ่นละ 1 ใบ
- **ผู้รับ 2 คน**: กด "+ เพิ่มผู้รับคนที่ 2" แล้วสลับแท็บ ใบที่ 1 / ใบที่ 2 เพื่อแก้แต่ละใบ
- **ค้นหาลูกค้าเดิม**: พิมพ์ในช่องชื่อ (2 ตัวขึ้นไป) หรือเบอร์ (3 ตัวเลขขึ้นไป) แล้วแตะชื่อที่ขึ้นมา ข้อมูลเติมครบทุกช่อง
- **วางที่อยู่จากแชท** LINE / Facebook แล้วแยกชื่อ เบอร์ รหัสไปรษณีย์ให้
- **ปรับใบปะหน้า** (อยู่ใต้ตัวอย่าง เห็นผลทันที): ระยะขอบติดเทป 1.6 / 2.5 / 3.2 ซม., ตำแหน่งผู้รับ, ขนาดตัวอักษร 4 ระดับ
- ขนาดตัวอักษรและขอบเป็นหน่วยจริงบนกระดาษ (pt / มม.) ภาพบนจอตรงกับที่พิมพ์
- กดสั่งพิมพ์แล้วบันทึกผู้รับทุกใบลงสมุดรายชื่อให้เอง เลือกคนเดิมแล้วแก้ = อัปเดตคนเดิม ไม่สร้างซ้ำ

### ตั้งค่าเครื่องพิมพ์
กระดาษ **A4**, แนว **แนวตั้ง** (ครึ่ง A4) หรือ **แนวนอน** (A4 เต็ม), ขนาด **100% / ขนาดจริง** — ห้ามเลือก "พอดีหน้า / Fit"

### ซิงค์ Google Sheets
- เข้าใช้ด้วย **รหัสผ่านช่องเดียว** ต่อเครื่อง ใส่ครั้งเดียวเครื่องจำไว้
- รหัสผ่านไม่ได้เก็บตรงๆ ที่ไหน: เว็บและ Apps Script เก็บแค่ SHA-256 ของ `"parcel-label:" + รหัส`
- Sheet เป็นตัวจริง: แต่ละเครื่องส่งงานที่ค้าง (เพิ่ม/แก้/ลบ) ขึ้นไปก่อน แล้วดึงรายชื่อทั้งหมดมาแทนของในเครื่อง ลบที่เครื่องไหนก็หายทุกเครื่อง
- เน็ตหลุด: งานรออยู่ในคิว ส่งให้เองเมื่อกลับมาออนไลน์
- Apps Script: ใช้ `LockService`, ข้อมูลเก่ากว่าไม่ทับข้อมูลใหม่ (ดูจากเวลาอัปเดต), คอลัมน์ A–E เป็นข้อความ (เบอร์ไม่หาย 0)
- โค้ด Apps Script อยู่ใน `index.html` (`<script type="text/plain" id="appsScriptTemplate">`) กดคัดลอกจากหน้า "ใส่รหัสผ่าน" > "ตั้งค่า Google Sheet ครั้งแรก"

### เปลี่ยนรหัสผ่าน / ลืมรหัส
1. เปิดเว็บ > ปุ่ม Sheets > ออกจากระบบ
2. พิมพ์รหัสใหม่ แล้วเปิด "ตั้งค่า Google Sheet ครั้งแรก" > คัดลอกโค้ด Apps Script
3. วางทับใน Apps Script > Save > Deploy > Manage deployments > ดินสอ > New version
4. ทุกเครื่องจะเด้งให้ใส่รหัสใหม่เอง
